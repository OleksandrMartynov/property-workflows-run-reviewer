# Межі працівника: ін'єкція і вихід за межі (K13)

Аналіз без запуску моделі. «Код» — скрипт чи тест; «налаштування» — `.claude/settings.json` і прапорці `run.sh`;
«промпт» — `AGENTS.md`, `SKILL.md`, опис субагента. Головне правило: де захист лише в промпті — шукаємо, як
перенести його в код чи налаштування; що не перенесено — сказано прямо.

## Що працівник бачить

- Запускається лише з кореня цього репо (`run.sh:13` робить `cd` у теку скрипта), тож діє саме цей `.claude/settings.json`.
- Читання файлів у межах теки дозволене без правила (`dontAsk` пропускає читання в робочій теці); читання поза текою
  не дозволене жодним правилом, тож у `dontAsk` відхиляється. Простого `Read` в `--allowedTools` свідомо немає: він
  дозволив би читати будь-який файл на диску.
- У межах теки закрито: `.env*` (`.claude/settings.json:13-14`), еталони й оцінювач `tests/` (`:15`), звіт і журнали
  `docs/` (`:16`), `.git/` (`:17`). Правила `Read(...)` за документацією Claude Code застосовуються й до Grep та Glob
  (best effort), а також до `cat`/`head`/`tail` у Bash — але Bash і так дозволено лише для одного скрипта.
- Скрипт `scripts/review.mjs` читає файли сам, і правила `Read(...)` його не обмежують. Тому межа — у коді: лише
  `data/<тиждень>/` (`scripts/review.mjs:31`), `references/policy.json` і звіт лише з `out/` (`:231`).

## Що лишається лише в промпті і що варто змінити

- **Виклик перевіряльника.** Перевіряє лише наявність рядка `ВЕРДИКТ:` у звіті. Сильніше: хук `SubagentStop`, що
  дописує вердикт перевіряльника в окремий файл `out/verdicts/`, який `check-report` звіряє зі звітом.
- **Перевіряльник не читає `out/`.** Це лише промпт: deny `Read(/out/**)` закрив би `out/` і оркестратору, якому
  потрібні власні звіти для `check-report` (той читає файл скриптом, тож deny `Read(/out/**)` можна додати, якщо
  оркестратору не треба перечитувати минулі звіти, — варто спробувати в наступній версії).
- **ОС-рівень.** Скрипт міг би прочитати будь-що, якби його змінили, але змінити його агент не може (`Edit(/scripts/**)`
  у deny). Для жорсткої межі — sandbox Claude Code чи контейнер з монтуванням лише цієї теки.
